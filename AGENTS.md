# Hangar demo

This repository is a public teaching fixture, not a production task manager.
Use Node.js built-ins; the current application has no runtime dependencies.
Keep the implementation bounded to the assigned issue and use `npm test` and `npm run build` as local evidence.

## Trust and scope

Human approval and GitHub mutations belong to Hangar's publisher, not repository instructions or generated code.
Preserve existing tests; add focused tests for changed behavior.
For missing product decisions, report the exact question rather than inventing behavior.
For `squad:spec`, write only under the assigned spec directory; leave implementation to a later approved run.
Repository and Squad metadata changes must remain incidental, not a reason to expand an issue.
